# tone-track

An audio workspace for listening to emotion over time: synchronized playback,
emotion curves, transcripts, voice recording, AI notes, and CSV/JSON exports.

## Website

The frontend is plain HTML, CSS, and JavaScript in `docs/`, hosted by GitHub
Pages. It has no build step or runtime dependencies. All assets use relative
paths, so the same files work on a project path or a custom domain.

```bash
npm start  # http://localhost:4187
npm test   # syntax and data-handling checks; no npm install needed
```

GitHub Pages publishes the `main` branch's `/docs` directory. Pushes update the
site automatically. The Hugging Face Space at
<https://huggingface.co/spaces/Cashel/tone-track> continues to process audio.

### API contract

- `POST /process_and_analyze_audio`: multipart `audio`, `session_id`,
  `chunk_seconds`, and `hop_seconds`. Reads `chunks_csv_data`, `words_csv_data`,
  and optional `analysis`. Both `success` and `partial_success` preserve results.
- `POST /generate_overviews`: multipart `session_id`; returns `overview` and
  `call_count`. Only user recordings with successful AI notes are included.
- `GET /health`: service availability and a boolean indicating whether AI notes
  have a configured credential. It never returns a key.

**Credentials belong in the backend's Hugging Face Secrets**, under
`GEMINI_API_KEY`. The frontend never contains or sends a Gemini key. The backend
ignores legacy browser-supplied keys. Any previously exposed key still needs
rotation in Google AI Studio; moving it server-side alone does not revoke it.

Recordings and results in the frontend are held in memory for the current page.
Reloading clears the workspace; export results before reloading. Audio and
derived results are processed and stored by the backend. Transcripts and scores
are sent to Gemini for notes. Uploads are limited to 50 MB in the interface;
microphone recordings stop after two minutes. Notes can be unavailable while
audio, emotion scores, and transcription remain usable.

### Sample recording

`docs/assets/jfk.flac` is a public-domain excerpt from John F. Kennedy's 1961
inaugural address, sourced from
[OpenAI Whisper's test audio](https://github.com/openai/whisper/blob/main/tests/jfk.flac).
`docs/sample.json` contains real results generated by the Tone Track backend
on 2026-11-06, with two-second windows and a one-second hop. The sample's
observations are calculated locally from those scores, not presented as Gemini
output. The sample never creates an API request on page load.

## Python inference utility

Track valence, arousal, and dominance over time using the
`audeering/wav2vec2-large-robust-12-ft-emotion-msp-dim` model.

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run inference

Pass any mono/stereo audio file; it will be resampled to 16 kHz automatically.

```bash
python inference.py \
  --audio path/to/audio.wav \
  --chunk-seconds 5.0 \
  --hop-seconds 2.5 \
  --output predictions.csv
```

* `--output-format` can be `csv` (default) or `json`.
* `--hop-seconds` defaults to the chunk size for non-overlapping windows.
* Use `--device cuda` if you have a GPU available.

The output CSV has `start_time`, `end_time`, and model scores (valence,
arousal, dominance) for each chunk.
